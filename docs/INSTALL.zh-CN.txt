合盖工作开关 1.5.2 · Apple Silicon / ARM64

安装
1. 将「合盖工作开关.app」复制到应用程序文件夹或桌面的固定位置。
2. 打开应用。平时仅在后台运行，菜单栏有笔记本图标。
3. 桌面右键 → 编辑小组件 → 搜索「合盖」→ 添加中号「合盖控制」。
4. 打开「合盖工作」「镜像保活」，保持 iPad 解锁并点「连接 iPad 镜像」。
5. iPad 显示正常后再合盖。接电源和使用电池均可；本机 M4 MacBook Air 已实测。

完整小组件需要 macOS 14 或更新版本。其他设备与系统版本请先自行测试。
发布包采用 ad hoc 本地签名，未做 Developer ID 签名或 Apple 公证。
从 GitHub 下载到其他 Mac 时，系统可能提示来源验证；也可以从源码构建。

更新
先退出应用，把新版本覆盖到原安装位置。保留完整 .app，包括内嵌的小组件扩展。
首次启动新版本会自动重新注册本项目小组件，避免旧扩展版本驻留造成状态不刷新。
中号小组件提供两个开关磁贴、下方 iPad 入口和右下角刷新；原生玻璃外观跟随 macOS 小组件设置。
右下角悬浮面板已移除。需要控制窗口时，从菜单栏打开。

停止使用和卸载
先打开 Mac 上盖，再关闭两个开关。菜单栏关闭「登录时在后台运行」，退出应用，
移除桌面小组件并删除应用。合盖工作会暂停系统睡眠；放进包里前务必关闭。
