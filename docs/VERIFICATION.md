## 构建与发布核验

发布前从整理后的源码重新编译宿主、虚拟画布组件和小组件扩展，检查：

- bundle 标识、版本和 build number 一致。
- 三个可执行文件均为 ARM64，扩展含正确的 `_NSExtensionMain` 入口。
- 原生扩展启用沙盒，嵌套代码签名验证通过。
- 宿主只读状态命令能正常运行，不改动当前开关。
- ZIP 内容、可执行权限和签名保持完整；DMG 可挂载且内含完整应用。
- ZIP、DMG 和安装说明有 SHA-256 校验值。

这些检查与现场合盖测试互补，不代表所有 Mac、iPad 和 macOS 版本均兼容。
